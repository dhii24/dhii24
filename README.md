## 📌 Featured Projects

### 🗂️ [Project Management Tool](https://github.com/dhii24/project-management-tool)
**React · Node.js · Express.js · MongoDB Atlas · Redis · Cloudinary · Docker · Docker Compose · Nginx**

- Built a full-stack MERN project management application featuring workspace collaboration, member invitations, role-based access control (Admin, Manager, Member), and secure REST APIs.
- Improved analytics API response time by **~56% (493 ms → 216 ms)** in sample tests using Redis caching with 60-second TTLs and automatic cache invalidation on card mutations.
- Implemented Redis-backed rate limiting on authentication endpoints (**5 requests per IP per endpoint per 15-minute window**) to mitigate brute-force attacks.
- Containerized the frontend and backend using Docker and Docker Compose, configuring Nginx as a reverse proxy for API routing and maintaining separate development and production workflows.
- Reduced backend Docker image size by **~82% (1.71 GB → 313 MB)** through Alpine-based images and production-only dependency installation.
- Hardened Docker containers using non-root execution, dropped Linux capabilities, health checks, resource limits, and Docker Compose secrets for sensitive configuration.
- Reduced Docker Scout-reported image vulnerabilities from **23 to 7** by updating npm while retaining Node.js 22, and verified backend health and login functionality after rebuilding.
- Deployed the frontend on Vercel and backend on Render, integrating MongoDB Atlas for managed data storage and Cloudinary for media uploads.

### 🏋️ [Gym Member Management App](https://github.com/dhii24/Gym-Member-Management-App)
**Express.js · MongoDB · MVC Architecture**

- Built a backend application to manage gym members and operations with a full CRUD REST API for member data.
- Structured the codebase using a clean MVC architecture for maintainability and easy extension.

### 🤖 [LLM-Powered Chat Assistant](https://github.com/dhii24/LLM-Powered-Chat-Assistant)
**Groq API · Llama 3.1 · Node.js**

- Built an AI knowledge assistant on Groq and Llama 3.1, designed for real-time, low-latency inference.
- Added conversational memory so the assistant gives context-aware responses across a chat session.
